# CodeAlpha - Exploratory Data Analysis (EDA)
 
## About the Project
This project is part of my Data Analytics Internship at CodeAlpha.

The objective is to explore a dataset, identify patterns, discover trends, and generate meaningful business insights using Python.

- Understand the dataset.
- Identify missing and duplicate values.
- Perform data cleaning.
- Analyze trends and patterns.
- Create meaningful visualizations.
- Generate useful business insights.
